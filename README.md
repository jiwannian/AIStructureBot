# AI 建造机器人（AIStructureBot）

Factorio **2.0** 模组。进档即可用。

核心玩法就两步：

1. **规划模式**里免费摆已解锁建筑的幽灵  
2. **正常模式**里按 `Shift+B` 派 AI Bot 去建

Bot 缺料时会由近到远采集矿石，能手搓或已有对应机器的物品会瞬间合成。有多少料建多少。

## 安装

1. 把本仓库放到 Factorio 模组目录，文件夹名必须是 `AIStructureBot`：
   - Windows：`%APPDATA%\Factorio\mods\AIStructureBot`
2. 启动游戏，在模组列表启用 **AI 建造机器人**。
3. 进存档即可。模组会自动解锁配方，并在背包里发 **1 台** Bot（每人只发一次）。

也可以打成 `AIStructureBot_1.0.0.zip` 丢进 `mods` 目录。

## 怎么用

### 1. 放下 Bot

进档后背包里有 **AI 建造机器人**，放到地上。外形是蜘蛛机甲。

### 2. 规划（时间暂停）

按 **`Shift+P`**，或点工具栏蓝图图标 / 菜单「进入规划」。

- 角色留在原地，镜头可飞到地图任意处  
- 工厂、传送带、虫子停转  
- 左侧弹出已解锁建筑菜单，点一下放到光标上  
- 在地上连续摆，落下的是**幽灵**，不扣材料  
- 换物品：再点菜单里的另一种  
- 停手：`Q` 清光标  
- 再按 **`Shift+P`** 退出，时间恢复，镜头回到角色

### 3. 派工建造

按 **`Shift+B`**，或菜单「派/停 Bot」。

- Bot 去建当前表面上的规划幽灵  
- **再按一次 `Shift+B`** 停止。已建的留下，没建的幽灵还在  
- 有多少对应材料就建多少，不会因缺料卡死整单  
- 补料后再按 `Shift+B` 继续

### 缺料时 Bot 会做什么

1. 列出缺什么、缺多少  
2. 把缺口拆到矿石（例如电路 → 铜线/铁板 → 铜矿/铁矿）  
3. 由近到远去最近的矿或树采集，采够再停  
4. 能手搓的瞬间合成，并提示也可以用哪台机器做  
5. 必须用机器、而你还没建的：提示「请先建造石炉 / 化工厂……」  
6. 货舱里已有的中间产物会先用，不会重复去挖

Bot **不攻击虫子**，也尽量不当虫子的攻击目标。

## 快捷键

| 键 | 作用 |
| --- | --- |
| `F1` | 打开/关闭菜单 |
| `Esc` | 菜单开着时关闭菜单 |
| `Shift+P` | 进入/退出规划模式 |
| `Shift+B` | 派工 / 停止派工 |
| `Q` | 规划时清掉光标物品 |

可在「设置 → 控制 → 模组」里改。

## 菜单

`F1` 打开，可拖动。

- **总控**：进入规划、派/停 Bot、指派 Bot、取消/跳过任务  
- **蓝图**：可选，保存光标蓝图后盖章（不是主流程）  
- **资源**：背包 / 货舱 / 物流网、当前缺口、为什么在等  
- **设置**：施工半径、是否从背包/物流网取货、超时等

## 可调参数

菜单设置页和「设置 → 模组设置」都能改。

**玩家设置**

| 项 | 默认 | 说明 |
| --- | --- | --- |
| 搜索半径 | 512 | 提示附近矿点用 |
| 预警阈值 | 20 | 当前任务物品低于此数标红 |
| 物流网安全库存 | 50 | 从物流网取货时每种至少留下 |
| 施工半径 | 24 | Bot 走进该距离才复活幽灵 |
| 允许从物流网取货 | 关 |  |
| 允许从玩家背包取货 | 开 | 派工时也会自动打开 |
| 等待材料超时 | 180 秒 |  |

**地图设置**

| 项 | 默认 | 说明 |
| --- | --- | --- |
| AI 心跳间隔 | 30 tick | 越小越快，UPS 越贵 |
| 每拍最多放置数 | 8 | 大片规划可调低保帧数 |

## 它不会做的事

- 不会自己铺矿机、改你现有工厂的配方  
- 流体配方（炼油、硫酸等）不会自动处理，缺对应建筑会提示你去建  
- 家里若已有建设机器人网络，规划幽灵仍可能被家里机器人先建掉  
- 多人请各自指派 Bot，避免抢同一只

## 常见问题

**`Shift+P` 进了地图编辑器？**  
旧版本会。请更新到本仓库最新版并重载存档。规划不再进编辑器。

**派工后面板报 Unknown key？**  
旧翻译缓存。回主菜单重载存档，或重启游戏。

**Bot 只建了一座就去挖矿？**  
请用最新版。现在按剩余幽灵计料，建完一座会继续下一座。

**Bot 不动？**  
确认已经放下 Bot，并已按 `Shift+B`。再按一次是停止。规划模式里 Bot 不会开工，先退出规划。

**聊天说请先建造石炉 / 化工厂？**  
铁板等必须用熔炉，塑料等必须用化工厂。先在规划或正常模式里把对应建筑摆出来。
