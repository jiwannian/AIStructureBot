# AI 建造机器人（AIStructureBot）

Factorio **2.0** 模组。进档即可用。

核心玩法：

1. **`Shift+P` 规划**：免费摆已解锁建筑的幽灵，或从蓝图库盖章  
2. **`Shift+B` 派工**：AI Bot 采集、瞬间合成并建造；红图标过的建筑会一并拆除  
3. **维护模式**（可选）：另一只 Bot 补炮塔弹药、修好受损建筑

Bot 缺料时会由近到远采集矿石。能手搓或已有对应机器的物品会瞬间合成。有多少料建多少。

## 安装

1. 把本仓库放到 Factorio 模组目录，文件夹名必须是 `AIStructureBot`：
   - Windows：`%APPDATA%\Factorio\mods\AIStructureBot`
2. 启动游戏，在模组列表启用 **AI 建造机器人**。
3. 进存档即可。模组会自动解锁配方，并在背包里发 **1 台** Bot（每人只发一次）。

也可以打成 `AIStructureBot_1.3.15.zip` 丢进 `mods` 目录。

仓库：https://github.com/jiwannian/AIStructureBot

## 怎么用

### 1. 放下 Bot

进档后背包里有 **AI 建造机器人**，放到地上。外形是蜘蛛机甲。可放多只：一只建造，另一只维护。

### 2. 规划

按 **`Shift+P`**，或点工具栏蓝图图标 / 菜单「进入规划」。

- 角色留在原地，镜头可飞到地图任意处  
- **单人**会冻结全图（工厂、传送带、虫子停转）；**多人**只让规划者飞镜头，不冻别人的厂  
- 左侧弹出已解锁建筑菜单，点一下放到光标上  
- 点「蓝图库」按目录选蓝图，放到光标后可任意盖章  
- 在地上连续摆，落下的是**幽灵**，不扣材料  
- 按住拖放时每格只落一个，不会在同一格连放  
- 地下管道 / 地下传送带会等配对完成后再变成幽灵  
- 换物品：再点菜单里的另一种  
- 停手：`Q` 清光标  
- 再按 **`Shift+P`** 退出，时间恢复，镜头回到角色

### 3. 蓝图库

规划面板里点 **蓝图库**（原来「一键规划流水线」的按钮）。

- 分类与 [ControlNet 原版蓝图分享](https://controlnet.space/2023/05/05/game/factorio-blueprints/) 的文本目录相同  
- 已导入 35 张：蓝图簿、超市模块、生产模块、科研模块、其他模块、物流模块、石墙结构  
- 点一张蓝图放到光标，像原版蓝图一样旋转、盖章  
- 盖完会自动再拿回同一张，可连续摆  
- 「蓝图簿」是整本蓝图书，可在原版界面里再挑其中一页

### 4. 派工建造

按 **`Shift+B`**，或菜单「派工 / 催工」。

- Bot 去建当前表面上的规划幽灵  
- 红图（拆除规划器）标过的建筑会一并拆掉，材料进 Bot 货舱  
- 只有红标、没有幽灵时也会开工，不会立刻收工  
- **再按一次 `Shift+B` 是催工**，让建造 Bot 继续赶往工地  
- **停止请点菜单「停止派工」**。已建的留下，没建的幽灵还在  
- 有多少对应材料就建多少，不会因缺料卡死整单  
- 补料后再按 `Shift+B` 继续

### 缺料时 Bot 会做什么

1. 列出缺什么、缺多少  
2. 把缺口拆到矿石（例如电路 → 铜线/铁板 → 铜矿/铁矿）  
3. 由近到远去最近的矿或树采集，采够再停  
4. 能手搓的瞬间合成，并提示也可以用哪台机器做  
5. 必须用机器、而你还没建的：提示「请先建造石炉 / 化工厂……」  
6. 货舱里已有的中间产物会先用，不会重复去挖  
7. **所有已放下的 Bot 货舱互通**：一只缺料时会用其他 Bot 货舱里的材料来合成和建造  
8. 同一单里若有红标建筑，会先拆，拆下来的材料可能正好补建造缺口

Bot **不攻击虫子**，也尽量不当虫子的攻击目标。

### 5. 维护模式

`F1` 打开菜单，在总控列表里点一只 Bot，再点模式按钮切到 **维护**。

- 先统计全部炮塔弹药缺口，一次性采够并合成，再沿路补完  
- 再给烧煤的石炉、钢炉、锅炉补煤；下限/上限可在维护页改  
- 附近炉子缺煤时会插队，不会被一座还在补弹的炮塔一直占住  
- 货舱没煤时会自己去找煤矿，采到再回来补  
- 再修地上血量不满的建筑；只回满血，不建规划幽灵  
- 多只维护 Bot 时谁近谁做  
- 有建造任务时，维护 Bot 和建造 Bot **同时干活**，不会互相停掉  
- 维护规则在菜单「维护」里，再分成 **维修 / 补弹 / 补煤** 三个子页；改过的上下限、弹药/燃料种类和开关会按玩家记住，重进存档还在

「回到玩家身边」会让当前 Bot 停下手头活，走回你身边。

## 快捷键

| 键 | 作用 |
| --- | --- |
| `F1` | 打开/关闭菜单 |
| `Esc` | 菜单开着时关闭菜单 |

## 菜单

`F1` 打开，可拖动。

- **总控**：选 Bot、切建造/维护、进入规划、派工/催工、停止派工、召回  
- **资源**：背包 / 货舱 / 物流网、当前缺口、为什么在等  
- **设置**：矿点搜索半径、任务搜索半径（以玩家为中心搜幽灵/补弹/补煤/维修）、施工半径、是否从背包/物流网取货、超时等；改滑条或文本框会立刻写入，重进还在  
- **维护**：当前选中 Bot 的补弹与维修规则（弹药/燃料种类、上下限、开关按玩家保存）  

规划模式左侧另有物品栏和 **蓝图库**。

## 它不会做的事

- 不会自己铺矿机、发电厂或防御  
- 不会改你现有工厂的配方  
- 流体配方（炼油、硫酸等）不会自动处理，缺对应建筑会提示你去建  
- 家里若已有建设机器人网络，规划幽灵仍可能被家里机器人先建掉  
- 多人请各自指派 Bot，避免抢同一只  
- 维护 Bot 只补弹和维修，不会去建规划幽灵

## 常见问题

**`Shift+P` 进了地图编辑器？**  
旧版本会。请更新到本仓库最新版并重载存档。规划不再进编辑器。

**派工后面板报 Unknown key？**  
旧翻译缓存。回主菜单重载存档，或重启游戏。

**Bot 只建了一座就去挖矿？**  
请用最新版。现在按剩余幽灵计料，建完一座会继续下一座。

**红图标了建筑，Bot 却不拆？**  
请用 1.2.0 及以后。纯拆除任务（0 个幽灵）以前会立刻收工。现在会先拆红图标记，材料进货舱。

**蓝图库盖完一张就没了？**  
请用最新版。盖完会自动再拿回同一张蓝图。

**派工后游戏很卡？**  
请用 1.2.2 及以后。旧版每只 Bot 每拍都会重扫幽灵、全队货舱和大范围矿点。

**走动几步就卡一下？**  
请用 1.3.15 及以后。1.3.14 把补弹/补煤扫描改成以玩家为中心后，每走几步都会重扫工厂。现在同一片区域会缓存约 5 秒。任务搜索半径也可以先调小（例如 128）。

**Bot 不动？**  
确认已经放下 Bot，并已按 `Shift+B`。再按一次是催工，不会停止。要停请点菜单「停止派工」。规划模式里 Bot 不会开工，先退出规划。维护模式的 Bot 也不会去建造，先在总控切回建造。

**聊天说请先建造石炉 / 化工厂？**  
铁板等必须用熔炉，塑料等必须用化工厂。先在规划或正常模式里把对应建筑摆出来。

## 版本

当前 **1.3.15**

- 维护扫描结果会缓存约 5 秒，玩家没走出 32 格就不再重扫工厂，走动时不再每几步卡一下
- 设置页新增「任务搜索半径」：以玩家为中心搜索待建幽灵、缺弹药炮塔、缺煤炉子和待修建筑，可用文本框直接输入
- 设置页每个数值都带文本框，不必只靠滑条
- 维护菜单的弹药/燃料上下限和开关会按玩家保存，重启后不再回到默认
- 设置页改滑条或勾选会立刻写入，不必再点确认
- 规划模式对着幽灵右键可以取消，手里拿着规划物品时也能拆掉
- 规划模式摆内燃机车会按落点朝向转幽灵，不再一律朝上
- 规划模式可以正常摆建筑；机车朝向在幽灵创建后再写入，不再把普通建筑创建打回
- 炮塔弹药低于或等于下限、且类型不是指定弹药时，先销毁旧弹再补指定弹药
- 炮塔弹药已到上限后不再去补，维护 Bot 闲下来会停住，不再在炮塔和钢炉之间来回
- 维护补弹/补煤会用所有 Bot 货舱里的弹药和煤，不再只看自己这一只
- 机枪炮塔缺弹会被正确识别并补上，不再被弹药类别解析或空炉插队挡住
- 补弹走到矿上后会真正采集/合成，不再只赶路
- 炮塔弹药等于下限时也会补到上限
- 维护 Bot 走到煤矿后会真正采够再回来补，空炉不再只走到矿上停住
- 空炉优先于补弹；没有燃料槽的电炉不会被当成缺煤
- 炉子/锅炉燃料等于下限时也会补到上限，不再卡在刚好 5 个煤
- 维护补煤时货舱没煤会自己去找煤矿采集  
- `Shift+B` 文案改为派工/催工，停止只在菜单  
- 附近炉子缺煤时会插队，不被一座炮塔占死  
- 维护 Bot 补弹会锁住一座炮塔，补到上限才换下一座，不再两座之间来回  
- 炮塔补不进弹时不再卡在塔旁，会继续去给炉子补煤  
- 维护 Bot 不再在炮塔附近来回走：有弹药先补，目标锁定后再换下一座  
- 维护菜单拆成维修 / 补弹 / 补煤三个子页，方便查找  
- 维护模式可给石炉、钢炉、锅炉补煤，上下限与补弹一样可调  
- 维护 Bot 工作时按 Shift+B 也会入队并给出文字提示  
- 维护 Bot 和建造 Bot 同一拍协同工作，不再互相卡住  
- 派工建造不再每拍全图重扫幽灵、货舱和矿点，卡顿明显下降  
- 规划拖放不再在同一格重复摆幽灵  
- 地下管道 / 地下传送带等配对完成后再转幽灵  
- 所有已放下的 Bot 货舱互通，可互相取料合成和建造  
- 规划面板「一键规划流水线」改为蓝图库，可任意盖章  
- 导入 ControlNet 原版蓝图，分类与网站文本目录相同  
- 修复纯拆除任务提前收工  
- 建造 / 维护双模式、召回、红图拆除进货舱
